# OCS Inventory on Docker

Spin up **OCS Inventory 3.0** — the Django REST API, the Vue single-page UI and
PostgreSQL — as a clean, secure, **upgrade-friendly** stack behind a single
hostname.

## Highlights

* 🔒 **Production-ready** — non-root, slim multi-stage images; gunicorn +
  WhiteNoise behind an nginx TLS edge; healthchecks; logs to stdout.
* ⬆️ **Upgrade-safe** — built from pinned upstream tags; migrations run
  idempotently before the app starts; your data and `SECRET_KEY` survive every
  update.
* 🎛️ **Runtime-configurable** — UI & API base paths, public ports and the backend
  URL are chosen at container start — no image rebuild.
* 🌐 **Single hostname** — UI under `/front/`, API and agents under `/api/`, same
  origin (no CORS to wrangle, configurable).
* 🧬 **Multi-version** — one set of parameterized Dockerfiles plus a
  `versions.json` manifest; CI builds every OCS release for amd64 & arm64.
